# Тауарларға сұранысты есептеу жүйесі

Python тілінде тауарлардың сатылымын есептейтін шағын жоба.

## Функциялары
- Жалпы сатылымды есептеу
- Орташа сатылымды есептеу
- Сұраныс деңгейін анықтау

## Технологиялар
- Python
- pytest
- Git
- GitHub Actions

## Орнату
pip install -r requirements.txt

## Тестті іске қосу
pytest

## CI/CD
GitHub Actions код репозиторийге жіберілген кезде
жобаны тексеріп, автоматты тесттерді орындайды.
